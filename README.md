# Prodigy Infotech - Web Development Internship Portfolio

Welcome to my repository containing the projects I successfully developed during my Web Development Virtual Internship at **Prodigy Infotech**. This repository showcases 5 frontend web applications built using HTML5, CSS3, JavaScript (ES6+), and live Web APIs.

---

## 📂 Project Structure Overview

Each folder contains the independent standalone source files (`index.html`, `style.css`, and `script.js`) for the respective tasks.

- **`/ptask1`**: Responsive Landing Page
- **`/ptask2`**: Precision Stopwatch Web Application
- **`/ptask3`**: Interactive Tic-Tac-Toe Game Matrix
- **`/ptask4`**: Personal Developer Portfolio Website
- **`/ptask5`**: Real-Time API Weather Forecasting App

---

## 🚀 Deep-Dive into the Tasks

### 🔹 Task 01: Responsive Landing Page
* **Description:** A modern, highly responsive corporate landing page built using flexbox and custom layout alignments.
* **Key Features:** Features a sticky header navigation bar that automatically decreases in size and transitions from a dark hue to a solid accent color when the user scrolls beyond 50px down the viewport.
* **Tech Stack:** HTML5, CSS3 Grid/Flexbox, Event Driven Vanilla JavaScript.

### 🔹 Task 02: Precision Digital Stopwatch
* **Description:** A pixel-perfect digital stopwatch designed around modern glassmorphism aesthetic styling principles.
* **Key Features:** Keeps time down to precision centisecond (10ms) intervals using the global execution loop engine. Built with full action event mapping logic handling Start, Pause, Reset, and instant Split-Lap tracking row allocations.
* **Tech Stack:** JavaScript Object Metrics (`Date.now()`), DOM Manipulation.

### 🔹 Task 03: Tic-Tac-Toe Web App Game
* **Description:** A responsive browser-based puzzle board environment allowing multiple local players to compete seamlessly.
* **Key Features:** Utilizes a custom 3x3 CSS Grid layout configuration array matrix that actively reviews 8 strict index winning directional pathways across state logs to automatically declare clear matching victories, register grid draws, or freeze user selection clicks upon round conclusions.
* **Tech Stack:** CSS Grid, State Arrays tracking logic, Conditional loop algorithms.

### 🔹 Task 04: Personal Developer Portfolio
* **Description:** A fast, multi-device compatible digital curriculum showcase that compiles an engineering background summary, structural education metrics, and custom skills cards.
* **Key Features:** Employs dynamic modern scroll transitions, light-to-dark gradient contrast patterns, and interactive scale elements that shift colors cleanly on cursor hover signals.
* **Tech Stack:** Semantic HTML Frameworks, Complex CSS Styling Sheet Animations.

### 🔹 Task 05: Asynchronous Weather Reporting Dashboard
* **Description:** A responsive, interactive dashboard engine communicating securely with external meteorological data servers.
* **Key Features:** Implements asynchronous `fetch()` API operations paired with comprehensive error catching systems (`try/catch`). It accepts user city parameters, extracts real-time objects data packages from the OpenWeatherMap API server pipeline, and displays matching results (Temperature, Humidity, Wind Speeds) smoothly on screen.
* **Tech Stack:** Asynchronous Javascript (`async/await`), JSON Data Stream Parsing, REST APIs.
